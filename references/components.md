# 八套组件细化版

默认生成（或显式使用 `--edition components`）八套组件细化版，`--theme all` 输出八套。蓝调网格和荧光便签已获用户“基本可以”的反馈，其余六套已迁移待视觉确认。`--edition pilot` 继续只输出 1、4 两套，旧稳定版须显式使用 `--edition stable`。

## 先判断用途，再选组件

由 Agent 读取原稿并完成语义编辑，渲染器负责确定性呈现。渲染器不猜关键词、不臆造署名和结论。文章解析一次；八主题共用同一个 article.json 和 editorial_plan。

1. 保留原文结构、段落、事实、来源、代码、媒体。非 Markdown 先按 intake.md 归一化并确认结构；Word 可用 read_word.py 生成材料记录，再核对原稿。
2. 判断主导文章类型，在 editorial_plan 写明配方和强调决策。未标记的正文，主动挑选 1–3 个有意义的短语用 ++下划线++；没有可提炼重点的段落可不标。不得整段标记，不逐句划线。
3. 默认不改文字，原始 **加粗**保留加粗语义；++下划线++ 为基础重点；==高亮== 用于少数强锚点；~~荧光笔~~ 按本组件映射规则，不解释为删除线。真正需要删除线的输入暂不支持，不能静默改成荧光笔。代码内不解析这些标记。
4. 核心金句与强高亮合计宜不超过五处；引用原话用 regular，个人解释用 aside。风险不只靠颜色，还要有“风险提醒”文字标签。
5. 导读只使用原文已有内容，不从章节再提炼三点或复制章节生成新导读。补导读须用户明确同意，并纳入新原稿基线。toc 明确保存文字，不伪造可点击正文导航。
6. 按中文章节拟定相关英文 label。结语章节可设 ending=true，仅最后一个章节显示 ∞。
7. 作者签名只留末尾一次；原文已有署名合并入 signature。按 SKILL.md 的署名规则填入已知资料，未知显示“作者姓名” / “一句话介绍自己”，不显示双大括号；使用紧凑的图标与两行文字布局；无原文 CTA 时使用默认互动句（感谢阅读。欢迎留言分享你的看法。），用户要求省略时不加。封面不放未知作者占位。
8. 中文标点和原文一同保留；不把半角自动换成全角，代码/URL/专名保持原样。必须以 --source 做文字核对；见 [文字保真规则](content-preservation.md)。不能只核对总字数。

## 配方

| 文章类型 | 核心组件 | 点缀 | 节制 |
|---|---|---|---|
| 教程 | 正文、步骤、代码、行动建议 | 风险提醒、旁注 | 不把每个段落变成提示卡 |
| 观点 | 正文、普通引用、少量核心金句 | 引言、轻量旁注 | 留出连续阅读的正文空间 |
| 复盘 | 正文、时间线、前后对比、实际数据 | 行动建议、结论 | 无来源的数据不补 |
| 工具盘点 | 条目说明卡、要点列表、对比 | 标签、代码 | 每张卡字段尽量一致 |
| 访谈 / 随笔 | 正文、原话引用、轻量旁注 | 时间线、引言 | 不强塞数据卡和步骤 |

## 输入扩展

保留原输入契约的所有块。新增或细化如下：

| 块 | 字段 / 变体 |
|---|---|
| intro | text，attribution?，label?；独立引言卡 |
| toc | title?，items:字符串列表；正文内导读 |
| quote | text，attribution?，variant:regular/key/aside；旧 emphasis 仍兼容 |
| note | title?，items:字符串列表，variant:info/action/warning |
| list | items，ordered:boolean；默认无序 |
| timeline | items:[{label,text}]；不虚构时间 |
| compare | title?，items:[{title,text},{title,text}]；两项对比 |
| cards | title?，items:[{label?,title,text}]；启用主题原有普通卡片 |
| code | text，language?，variant:light/dark；原样保留字符与换行 |
| placeholder | text；用户确认尚未补齐的素材说明 |
| conclusion | title?，text，label?；沿用原文总结 |
| signature | name，bio?，cta?；至多一处且必须末尾 |
| chapter | 新增 ending?；最后章节可使用结语编号 |

顶层可加 article_type 与 editorial_plan（仅记录不进入正文）。cover 可用 lines:标题分行列表、focus:某一行、label、tab、footer。lines 必须完整保留原标题；focus 不新增词。只有明确提供时才加角标/页脚。蓝调恢复网格分栏、大箭头；荧光恢复大词、绿框、黄色底部便签。

本版本的图片、表格、数据卡、步骤继续复用稳定版。表格仍展开为标记字段卡片；GIF 无独立角标；相关限制须在实际使用时如实说明。八套渲染器未增加 FAQ、品牌墙、复杂图表；当前不提供新增自定义主题生成与登记流程。雾蓝超过六章后按六章明暗模式循环，章节编号和导航仍连续。

## 检查

输出干净正文和预览；静态校验零错误/警告；320/390px 检查溢出、代码换行、浅/深底文字；检查章节切换和唯一署名；同源内容不能因主题不同增减。验证报告区分静态、浏览器和公众号实贴，后者未做须明确说明。

## 六套新增实现的区别

| 主题 | 封面 | 引用 / 提示 | 对比 / 时间线 |
|---|---|---|---|
| 黑紫未来 | 黑色圆角主卡、紫胶囊、跨卡星徽、大词 | 紫色重点、浅紫补充、黑色风险 | 黑紫双卡；胶囊编号的分段时间线 |
| 橙青映像 | 橙青渐变、等宽大词、细线星点底栏 | 青底重点、橙线风险、错位通栏 | 橙青双区；细线递进 |
| 曜黑酸柠 | 通篇黑底、轻标题、顶部箭头、渐变胶囊 | 渐变重点、线框补充、白底风险 | 深底与酸柠对照；开放分隔时间线 |
| 复古唱片 | 黄蓝红边框、圆润字、右上唱片、偏移阴影 | 纸色引语、蓝底黄字重点、硬阴影风险 | 黄蓝边框卡；彩色粗侧条时间线 |

不把所有组件统一成换色圆角卡；基础文字、数据、步骤、普通条目卡继续使用对应主题规则。
